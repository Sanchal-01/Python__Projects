======================================================================
PROJECT NOTES: GOOGLE GEMINI CHATBOT (ORION)
======================================================================

Overview:
---------
This is a simple command-line chatbot (like Jarvis/Orion) that uses Google's Gemini API. It can remember past messages in a conversation. 
It also uses an environment file to keep the secret API key safe.

# Main Features:
 1. Shows a welcome message at startup.
 2. Runs an infinite loop to keep talking to the user.
 3. Saves the chat history automatically.
 4. Connects securely to Google's servers.
 5. Gets the text response directly.
 6. Type "exit", "quit", or "bye" to close the chatbot.

----------------------------------------------------------------------
1. SETUP & TOOLS NEEDED
----------------------------------------------------------------------
A. Libraries to Install:
   - `google-genai`: The official modern package to use Google Gemini.
   - `python-dotenv`: Tool to read secret keys from a hidden file.

B. Key Files:
   - `.env`: A hidden text file to store your `GEMINI_API_KEY`.
   - `.gitignore`: Tells Git to hide the `.env` file so my key is never uploaded to GitHub.

C. Important Code Variables:
   - `client`: Opens the connection using your secret API key.
   - `chat`: The active chat room that remembers the conversation.
   - `user_question`: Stores what the user types.
   - `response`: Stores what Gemini replies.

--------------IMPROVEMENT--------------
D. Hidden Key Security:
   - Instead of pasting the secret key directly into the code, we use `os.getenv()`. This keeps my account safe from hackers.



----------------------------------------------------------------------
2. HOW THE CODE WORKS (STEP-BY-STEP)
----------------------------------------------------------------------
The whole program runs inside a continuous `while True:` loop:

Step 1: Get User Input
   - Takes input using `input()`.
   - If the user types "exit", "quit", or "bye", the loop stops (`break`).

Step 2: Send Message
   - Sends the message using `chat.send_message(user_question)`.
   - Google automatically manages the history for you behind the scenes.

Step 3: Show the Reply
   - Uses the model `gemini-3.6-flash`.
   - Reads the clean reply using `response.text`.
   - Prints the text to the screen using single quotes to avoid errors.



----------------------------------------------------------------------
3. EXAMPLE RUN (WALKTHROUGH)
----------------------------------------------------------------------
- Game Starts: Prints "Orion: Hi I am Orion, How may I help you?"
- User types: "what is the capital of France"
- The code packages this question and sends it to Google.
- Google's servers process it and reply: "The capital of France is Paris."
- The chat memory saves both the question and the answer.
- Screen prints: "Orion: The capital of France is Paris."
- The loop resets and waits for your next question.

----------------------------------------------------------------------
4. FUTURE IMPROVEMENTS
----------------------------------------------------------------------
1. Clear History: Add a custom command (like "clear") to empty the chat memory if the conversation gets too long.
2. Error Handling: Put the network requests inside a try-except block to show a clean error message if your internet drops.
